# Memory Index

This directory stores persistent session memories — context about the project, user preferences, and learnings that carry across conversations.

## Memory Types

- **user** — Information about the user (role, expertise, preferences)
- **feedback** — Guidance on how to approach work (what worked, what to avoid)
- **project** — Project-specific context (goals, deadlines, architecture decisions)
- **reference** — Pointers to external resources (tracking systems, docs, dashboards)
